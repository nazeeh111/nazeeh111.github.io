# MaterialMind source and foundations

WBM structures, labels and published CHGNet predictions come from the Matbench Discovery collection by Janosh Riebesell and contributors (CC BY 4.0), with the original Wang–Botti–Marques WBM study credited. CHGNet 0.3.0 is a frozen BSD-3-Clause foundation; the residual model and acquisition study are the project’s work. Code and bundled Three.js are MIT licensed with their respective notices.

This is retrospective evaluation against previously computed DFT labels. It reports no new DFT calculations, synthesis or newly discovered materials; the fitted policy did not beat adapted greedy.

Recorded case source: https://github.com/nazeeh111/MaterialMind/tree/8d11857fd54d93d1f5159e7e5105e1f927ccf33d

The original screenshot/diagram files are copied unchanged. This site does not redistribute the native worked package or run a new experiment.
