# SILICONPILOT source and foundations

Original small RTL backend using established ML-to-FPGA and surrogate-search ideas. Icarus Verilog, Yosys and nextpnr supply simulation, synthesis and routing. Four precomputed input features come from Volker Lohweg’s UCI Banknote Authentication dataset (CC BY 4.0), not raw camera frames. Source is Apache-2.0; retain its license and upstream dataset/tool notices.

These are recorded simulations and FPGA-tool estimates, not board measurements. The pictured 0.1.0 corpus is preserved separately from the newer 0.1.1.dev0 compiler.

Recorded case source: https://github.com/nazeeh111/SILICONPILOT/tree/61badd38086dc8c0395fff3dfd814f4073c90b93

The original screenshot/diagram files are copied unchanged. This site does not redistribute the native worked package or run a new experiment.
