Data and reproduction

The panels display retained two-dimensional numerical data. They run no solver and report no device measurement.

The portable package contains a 203,779-byte minimal extraction preserving every value used by the figures. It omits unused fields from the 733,968-byte original JSON. The original and extracted hashes are distinct and recorded in sources.json.

Figure meaning

The field is signed Re(Ey) relative to unit incident amplitude at 1550 nm, not intensity. Equal spatial scale, saved geometry and all 97×96 samples remain visible. The legacy M9 formulation supplied the field; search used M5.

The spectrum contains 21 solves from 1300 to 1700 nm in 20 nm steps. Its circles are stored solves; straight segments only connect them. The separate 1550 nm design solve is not a sample in this curve.
