Chronal

Chronal froze its winning strategy. On fictional holdout prices, it lost 1.461%. Follow the simulated trades behind that result.

Open the interactive holdoutDownload the complete replay
How to find the first fill

In the report, set Inspect exact session date to June 3, 2020 and choose Execution from the section menu. With a keyboard, press /, enter session #2, then enter goto execution.

A 1.461% loss on the holdout

The selected strategy returned +1.775% in development and −1.461% on the holdout. Equal weight returned −4.528% on the holdout. The selected strategy incurred 233.486 units of holdout commission. Spread and slippage enter fill prices.

Interpretation

This experiment uses fictional prices. Session numbers in the figure are zero-based. The terminal’s session command counts from one within the displayed period. Results describe this run under Chronal’s daily execution assumptions.

When a development winner loses

A strategy can win on development data and still lose on the next unseen period. The worked experiment freezes the candidate, fill rules and costs so a reader can trace how that result arose.

Freeze the strategy before evaluation

Training and evaluation advance in chronological windows. Chronal ranks four candidates by development Sharpe, freezes trend60, then compares it with equal weight across 126 holdout sessions. Both start the holdout with 100,000 simulated account units.

Foundations

Chronal uses Python and NumPy for chronological fitting and cash-aware simulation. The saved terminal contains the recorded data and runs in the browser with no external dependencies.
