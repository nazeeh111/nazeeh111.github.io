Interpretation

This is one observed prepared Orbit example. The workbench comparison is not an independent native oracle, a new codec, universal binary compatibility or a security-isolation proof. The exact source revision of this retained screenshot was not recorded.

An initialized decoder

A native component can depend on initialized state and owned memory, not just a function address. Reusing it requires preserving that state and an explicit calling contract.

Reopening the allocation

Capsulith packages selected ARM64 functions with calling contracts and owned memory. The image workbench runs the prepared QOI decoder through native-code emulation, retains the decoded allocation, then reopens it in a fresh worker. Pixel inspection and native free expose the memory lifecycle instead of hiding it behind a static preview.

Foundations
