VibeScope

Measure small motion from original video frames, then change the display gain without changing the displacement history or frequency estimate.

Run locallyInspect paired-run evidence

This is controlled synthetic image-plane evidence. Physical calibration, arbitrary-media and diagnostic accuracy are not established. Timing was explicitly unverified because ffprobe was unavailable; magnification is a visualization, not a new sensor measurement.

The problem

A convincing magnified video is not a displacement measurement. Display enhancement must remain separate from the original-frame signal used for quantitative analysis.

The mechanism

VibeScope tracks a selected image region against an independent stationary reference, derives displacement and frequency information from original decoded frames, and renders motion visualization separately. Exported reports, CSV and saved-run history retain the settings and measurement records.

The observed result

The recorded gain-5 and gain-20 runs have identical complete 240-sample signals, quantitative metrics and raw displacement CSV bytes, while their visualization settings and enhanced output differ. For the controlled 7.3 Hz / 0.28 px input, the observed result was 7.299959660082684 Hz / 0.2798920570385787 px. The saved gain-20 run reopened after server restart.

Foundations

Core inference runs in NumPy. The project separately credits its classical and learned research foundations; the optional EulerMormer runner invokes an external model and is not bundled into the core estimator.

Inspect the details

The original and enhanced frame pixels are retained at native 320 × 192 resolution; nearest-neighbor enlargement changes display size only. No selective contrast, color or denoising adjustment was applied for the portfolio figure.

The figure reads the browser-exported reports and CSVs. It performs no new estimator, fit, filter or physical experiment.
