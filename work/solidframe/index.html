SolidFrame

Build and edit native mechanical solids in a browser, with a complete CAD workspace rather than a static model viewer.

Try in browserRead the modeling guide

One edit through Undo and Redo

In the recorded deployed workflow, Open editable sample created seven native solids. Editing the selected base plate changed Width from 70 to 85 mm. Undo returned it to 70 mm; Redo restored 85 mm, with all seven parts retained.

Interpretation

The fixture contains independent editable solids, not a constraint-solved assembly or a manufacturing-approved design. This capture verifies the shown edit and history sequence, not every CAD command or export format.

Editable dimensions

A useful browser CAD tool needs editable geometry, reversible changes and portable documents. A rendered mesh alone cannot carry the dimensions that produced a part.

From dimensions to native solids

SolidFrame builds on Chili3D and OpenCascade. The mechanical-part workflow turns dimensions and hole layouts into native solids, while the editable fixture exposes separate parts in the model tree. Properties edits rebuild geometry; the command history makes changes reversible. Local browser snapshots and editable .cd downloads serve different storage needs.

Foundations

Adapted from Chili3D and built on OpenCascade. The AGPL-3.0 source license and the C++/WebAssembly notice remain with the project and the retained case assets.

Sources and supporting evidence

Native .cd documents preserve editable project structure. Exchange exports such as STEP and STL carry geometry; they do not promise to preserve all builder settings.

The project includes a drilled-plate and bracket builder with whole-configuration validation. Its ideal geometry does not calculate strength, bend allowance or fabrication approval.
