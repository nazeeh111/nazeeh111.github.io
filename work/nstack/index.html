Interpretation

Finding a capability by task

A list of agent skills does not explain when a capability applies, what it depends on or which licensed source will be installed. Discovery needs to stay separate from activation.

The reviewed capability registry

nstack keeps a reviewed capability registry with source revisions, selected paths, rights, activation conditions and task checks. Its search, show and route commands expose those decisions before installation. A component can contain several native skills; its catalog identifier is not the same as an installed skill name.
