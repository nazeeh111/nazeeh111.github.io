Solidrift

Shrink a native mesh Boolean failure while preserving the bug, then inspect a reversible geometry intervention and its source ancestry.

Inspect recorded caseRead the reducer source

132 triangles reduced to 12

The retained investigation reduces 132 input triangles to a 12-triangle witness through 60 accepted contractions. Its recorded intervention moves three witness vertices whose ancestry covers thirteen original vertices. Undo restores the original input coordinates and the native omission. The two portfolio panels show the original 132-triangle stage, not the later witness.

Interpretation

The browser viewer replays stored geometry and never runs Blender. This is a bounded greedy reduction, not a globally smallest witness. The intervention changes the input geometry, not Blender’s implementation; agreement with MANIFOLD is not proof of an ideal union.

A Boolean union drops material

A Boolean union quietly drops part of the input. Sending the full model is easy; reducing it to a valid, small example that still reproduces the same failure is harder.

Reduce the mesh, preserve the failure

Solidrift contracts edges while checking that both operands remain valid closed solids and the same native failure survives. It tracks each vertex’s source ancestry, searches small boundary interventions on the witness, lifts a selected intervention back to the full inputs, and records native repair and undo results.

Foundations

The two operands are Manifold regression fixtures under Apache-2.0, not original models. Blender supplies the FLOAT and MANIFOLD Boolean implementations. Solidrift’s implementation is MIT licensed, with fixture attribution retained.

Sources and supporting evidence

This case is tied to the retained Blender 5.3.0 Alpha build bad8871dc58d record at the cited source revision. Newer public investigations have separate backend identities and must not be merged into this older capture’s provenance.

The compact case bundles original identities, reduced and restored operands, contraction trace, coordinate patch, validity checks and backend identity. Intermediate input states can be replayed without inventing intermediate native output surfaces.
