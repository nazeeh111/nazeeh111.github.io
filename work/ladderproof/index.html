LadderProof

Find when a higher digital code produces a lower voltage, then choose resistor tolerances that prevent it.

Run the tolerance workflow locallyInspect the exact six-bit certificate

A reversal at code 31 to 32

The included six-bit ±5% case decreases at code 31→32, while the ±1% case has no decreasing step across all 4,096 modeled corners. In the synthetic two-bit catalog, tightening B1 and S0 meets the 1/5 V requirement for cost 2 rather than cost 4 for every part. The chosen exact worst step is 151/731 V; the all-loose baseline is 68/409 V.

Interpretation

Exact results apply to the declared ideal static 2–6-bit circuit and independent resistor intervals. Catalog costs are synthetic units, not part prices; this is not measured hardware or manufacturing yield.

When the next code lowers voltage

A digital-to-analog converter should increase its output as the input code increases. Resistor variation can reverse a step. Knowing the worst allowed step and which tolerances repair it turns a bad example into a design decision.

Exact corner enumeration

LadderProof enumerates every admitted corner of a small resistor-tolerance box using exact fractions. A nodal circuit solve finds the worst adjacent-code transition and attaining resistor assignment; a separate Thevenin-based verifier recomputes the complete bounds. A finite catalog search trades user-defined component costs against a required minimum step.

Foundations

Established R–2R circuit analysis and exact arithmetic, implemented as an inspectable bounded analyzer with a separate complete verifier. The project credits its model references and keeps its MIT license. It is not a SPICE replacement or an invention of the converter architecture.

The recorded browser workflow exercised optimal selection, finite exhaustion/infeasibility, a work-limit stop, malformed exact-fraction recovery and independent Verify and use selection. The successful two-bit selection was independently recomputed over 16 corners and 3 adjacent transitions.

The model assumes ideal switches, a fixed positive reference and unloaded output. Independent intervals do not model matched/correlated resistor families. Switching glitches, settling, temperature, noise, reference regulation and physical yield are outside the result.

Search returns optimal only under its exact cost-order/verification conditions, infeasible after exhausting the admitted finite catalog, and unfinished when candidate/corner/deadline limits stop it. Arbitrary additive costs are not prices. Certificates are replayable computations, not succinct formal proofs or cryptographic attestations.
